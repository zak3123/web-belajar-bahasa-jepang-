# 🚀 Deploy ke Vercel - Step by Step

## ✅ Kode Sudah Siap di GitHub!
Repository: https://github.com/zak3123/web-belajar-bahasa-jepang-

## 🌐 Cara Deploy ke Vercel (Paling Mudah!)

### **Step 1: Login ke Vercel**
1. Buka https://vercel.com
2. Klik "Sign Up" atau "Login"
3. Pilih "Continue with GitHub" (recommended)
4. Authorize Vercel untuk akses GitHub

### **Step 2: Import Project**
1. Setelah login, klik "Add New..." → "Project"
2. Di bagian "Import Git Repository", cari: `web-belajar-bahasa-jepang-`
3. Klik "Import"

### **Step 3: Configure Project**
Vercel akan auto-detect config. Jangan ubah apa-apa:
```
Framework Preset: Other
Build Command: (kosongkan - static site)
Output Directory: .
Install Dependencies: Otomatis detected
```

Klik **"Deploy"**

### **Step 4: Wait & Done!** ⏱️
- Build process ~30-60 detik
- Progress bar akan muncul
- Saat finished, website live!

### **Step 5: Get Your URL**
Website akan live di:
```
https://web-belajar-bahasa-jepang-.vercel.app
```

Atau bisa customize domain name saat deployment.

---

## 🎨 Custom Domain (Optional)

Setelah deploy, bisa ganti domain:

1. Login ke dashboard Vercel
2. Klik project → Settings → Domains
3. Tambahkan custom domain:
   - Beli domain .com (~Rp 150.000/tahun)
   - Atau pakai gratis subdomain dari Vercel

## ❓ Troubleshooting

### If build fails:
1. Check console logs di Vercel dashboard
2. Usually caused by missing files or syntax errors
3. Re-check all files are in root directory

### To view logs:
Dashboard → Builds → Click latest build → View logs
