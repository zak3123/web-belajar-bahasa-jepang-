## 🆘 TROUBLESHOOTING:

### If build fails:
- Check console logs di Vercel dashboard
- Ensure all files are in root directory
- Verify no syntax errors in app-data.js

### If site not loading:
- Clear browser cache (Ctrl+Shift+Delete)
- Try incognito mode
- Wait 2 minutes after deployment

### Check deployment status:
- Dashboard → Projects → Your Project → Deployments
- See latest build status and logs
