## 🚀 CARA DEPLOY (3 LANGKAH SAJA):

### **STEP 1: Buka Repository**

```
Browser buka: 
https://github.com/zak3123/web-belajar-bahasa-jepang-
```

Atau click link ini saat login GitHub:
[Repository Kamu](https://github.com/zak3123/web-belajar-bahasa-jepang-)

---

### **STEP 2: Enable GitHub Pages**

```
Click tab "Settings" di top menu repository
   ↓
Scroll ke bawah → Cari menu "Pages" (sebelah kiri)
   ↓
Di bagian "Source":
  - Dropdown: Pilih "Deploy from a branch"
  - Branch: Pilih "main"
  - Folder: "/ (root)"
   ↓
Click "Save"
   ↓
⏳ WAIT 30-60 seconds for build
```

---

### **STEP 3: DONE! Website Live!** 

Website akan live di:
```
https://zak3123.github.io/web-belajar-bahasa-jepang-/
```

**Test sekarang** - buka link tersebut di browser baru!

## ✨ CUSTOM DOMAIN (Optional):

Jika mau ganti domain:

```
1. Buy domain (.com ~Rp 150.000/tahun)
   Example: belajarbahasajepang.com
   
2. Go to Settings → Custom Domain
   Input: belajarbahasajepang.com
   
3. Configure DNS records (provided by GitHub)
   CNAME: belajarbahasajepang.com → zak3123.github.io
   
4. Wait 24-48 hours for DNS propagation
```

## 🆘 TROUBLESHOOTING:

### If site shows "404 Not Found":
- Wait 2-3 minutes after saving settings
- Sometimes takes time to generate first page
- Refresh browser (Ctrl+F5)

### If images/assets not loading:
- Clear browser cache (Ctrl+Shift+Delete)
- Try incognito mode
- Verify files are in root directory

### Check deployment status:
```
Settings → Pages → View logs
```

See latest build logs and errors.
